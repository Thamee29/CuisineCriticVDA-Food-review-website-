# 🍽️ CuisineCriticVDA — Full-Stack Food Review Website

**CuisineCriticVDA** is a full-stack **food review website** built with **Flask (Python)** for the backend and **HTML, CSS, and JavaScript** for the frontend. Users can create accounts, submit reviews, rate restaurants and dishes, and explore cafes ranked by user ratings.

---

## 📌 Key Features

- 📝 **User Authentication:** Secure sign-up and login functionality  
- ⭐ **Review & Rating System:** Submit and view ratings for restaurants and dishes  
- 🍴 **Cafe Listing:** View cafes sorted by average user ratings  
- ⚡ **Dynamic Content:** Flask backend serving interactive pages  
- 🖼️ **Responsive Frontend:** Clean and intuitive UI using HTML, CSS, JS

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)
